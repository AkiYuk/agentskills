## 共通ルール

### 見出しレベルの役割

| 見出し | 役割 | 説明 |
|--------|------|------|
| `#`（h1） | セクション名 | 自動的にsectionレイアウトとして扱う |
| `##`（h2） | スライドタイトル | 各スライドの上部に表示される |
| `###`（h3） | キーメッセージ | タイトル下に小さく表示される補足メッセージ |
| `####`（h4） | カラムヘッダー | two/three/four_columnレイアウトのカラム見出し |

### スライド区切り

- スライド間は `---`（水平線）で区切る
- レイアウト指定は `<!-- layout: レイアウト名 -->` コメントで行う
- レイアウト未指定の場合は `bullet_points` がデフォルト

## 1. title - 表紙

**用途**: プレゼンテーションの表紙

**背景色**: 紺色 `#1E3A5F`

**使用可能な要素**: タイトル（##）、サブタイトル（###）

**記法例**:
```markdown
<!-- layout: title -->
## プレゼンテーションタイトル
### サブタイトルや日付・発表者名
```

**デザイン注意点**:
- テキスト色は白 `#FFFFFF`
- タイトルは44ptで中央配置
- 1プレゼンで1回のみ使用する

## 2. section - セクション区切り

**用途**: 大きなトピックの区切り

**背景色**: 薄グレー `#F5F5F5`

**使用可能な要素**: セクション名（# または ##）

**記法例**:
```markdown
# セクション名
```

または明示的に指定:
```markdown
<!-- layout: section -->
## セクション名
```

**デザイン注意点**:
- `#`（h1）は自動的にsectionレイアウトとして扱われる
- セクション名は36ptで中央配置
- テキスト色は `#333333`

## 3. toc - 目次・サマリー

**用途**: プレゼン全体のアジェンダや構成を示す

**背景色**: 白 `#FFFFFF`

**使用可能な要素**: タイトル（##）、キーメッセージ（###）、箇条書き

**記法例**:
```markdown
<!-- layout: toc -->
## アジェンダ
### 本日お話しする内容をご紹介します

- 現状分析
- 課題の整理
- 解決策の提案
- ロードマップ
- まとめ
```

**デザイン注意点**:
- 項目数は3-7個が推奨
- 各項目は20文字以内

---

## 4. bullet_points - 箇条書き

**用途**: 汎用的な箇条書きコンテンツ（デフォルトレイアウト）

**背景色**: 白 `#FFFFFF`

**使用可能な要素**: タイトル（##）、キーメッセージ（###）、箇条書き

**記法例**:
```markdown
<!-- layout: bullet_points -->
## 主要な成果
### 今期の取り組みにより3つの成果が得られた

- 売上が前年比120%に成長した
- 新規顧客獲得数が目標の150%を達成した
- 顧客満足度が4.5点に向上した
```

**デザイン注意点**:
- 項目数は3-5個が推奨
- 各項目は50文字以内
- レイアウト未指定の場合のデフォルト

---

## 5. numbered_list - 手順・ステップ

**用途**: 順序のある手順やステップを示す

**背景色**: 白 `#FFFFFF`

**使用可能な要素**: タイトル（##）、キーメッセージ（###）、番号付きリスト（タイトル: 説明の形式）

**記法例**:
```markdown
<!-- layout: numbered_list -->
## 導入ステップ
### 3ステップで簡単に導入できます

1. 要件定義: ビジネス要件をヒアリングし要件を整理する
2. 環境構築: クラウド環境をセットアップし接続テストを実施する
3. 本番移行: データ移行と動作確認を経て本番稼働を開始する
```

**デザイン注意点**:
- 項目数は3-5個が推奨
- 各項目の「タイトル: 説明」形式で、タイトル15文字、説明50文字以内
- 番号は自動的にアクセント色の丸数字で表示

## 6. two_column - 2つの対比

**用途**: 2つの要素の対比・比較

**背景色**: 白 `#FFFFFF`

**使用可能な要素**: タイトル（##）、キーメッセージ（###）、カラムヘッダー（####）、本文

**記法例**:
```markdown
<!-- layout: two_column -->
## 導入前後の比較
### システム刷新により業務効率が大幅に改善された

#### Before
手作業でのデータ入力に毎日2時間を費やしていた。ヒューマンエラーも頻発し、月次集計に3日かかっていた。

#### After
自動化により入力作業がゼロになった。リアルタイムでデータが反映され、月次集計は即時完了するようになった。
```

**デザイン注意点**:
- カラムヘッダーは10文字以内
- 本文は80文字以内
- 左右均等に配置

---

## 7. three_column - 3つの並列

**用途**: 3つの並列要素の表示

**背景色**: 白 `#FFFFFF`

**使用可能な要素**: タイトル（##）、キーメッセージ（###）、カラムヘッダー（####）、本文

**記法例**:
```markdown
<!-- layout: three_column -->
## サービスプラン
### ニーズに合わせて3つのプランをご用意しています

#### ベーシック
月額1万円で基本機能を全て利用可能。小規模チームに最適。

#### スタンダード
月額3万円で高度な分析機能を追加。中規模組織向け。

#### プレミアム
月額10万円で専任サポート付き。大規模導入に対応。
```

**デザイン注意点**:
- カラムヘッダーは8文字以内
- 本文は60文字以内
- 3等分で配置

---

## 8. four_column - 4つの並列

**用途**: 4つの並列要素の概要表示

**背景色**: 白 `#FFFFFF`

**使用可能な要素**: タイトル（##）、キーメッセージ（###）、カラムヘッダー（####）、本文

**記法例**:
```markdown
<!-- layout: four_column -->
## 開発フェーズ
### 4フェーズで段階的にリリースします

#### Phase 1
基盤構築と認証機能の実装を完了する

#### Phase 2
コア機能の開発とAPI連携を実装する

#### Phase 3
UI改善と性能最適化を実施する

#### Phase 4
本番リリースと運用体制を確立する
```

**デザイン注意点**:
- カラムヘッダーは6文字以内
- 本文は40文字以内
- 4等分で配置。各カラムの幅が狭いため簡潔に書く

## 9. metrics - 数値・KPI

**用途**: 2-4個の重要な数値・KPIを強調表示する

**背景色**: 白 `#FFFFFF`

**使用可能な要素**: タイトル（##）、キーメッセージ（###）、テーブル（数値・ラベル形式）

**記法例**:
```markdown
<!-- layout: metrics -->
## 今期の実績
### 全てのKPIで目標を上回る成果を達成した

| 数値 | ラベル |
|------|--------|
| 120% | 売上達成率 |
| 450件 | 新規契約数 |
| 4.5 | 顧客満足度 |
```

**デザイン注意点**:
- 数値は大きなフォント（36pt程度）で表示
- ラベルは数値の下に小さく表示
- 2-4個が推奨。5個以上は comparison_table を使用する

## 10. quote - 引用

**用途**: 顧客の声、著名人の言葉、調査結果の引用

**背景色**: 白 `#FFFFFF`

**使用可能な要素**: タイトル（##）、引用テキスト（>）、著者名

**記法例**:
```markdown
<!-- layout: quote -->
## お客様の声

> このシステムを導入してから業務効率が劇的に改善しました。以前は丸一日かかっていた作業が30分で完了するようになり、チーム全体の生産性が向上しています。

-- 株式会社サンプル 田中太郎氏
```

**デザイン注意点**:
- 引用テキストは大きめのフォントで中央配置
- 引用符（"..."）で装飾
- 著者名は右寄せで小さく表示
- 引用100文字、著者20文字以内

## 11. faq - Q&A

**用途**: 想定質問とその回答をQ&A形式で表示

**背景色**: 白 `#FFFFFF`

**使用可能な要素**: タイトル（##）、質問（太字テキスト）、回答（通常テキスト）

**記法例**:
```markdown
<!-- layout: faq -->
## よくある質問

**Q. 導入にどれくらいの期間がかかりますか？**
A. 標準的な導入期間は約2ヶ月です。要件の複雑さに応じて前後する場合があります。

**Q. 既存システムとの連携は可能ですか？**
A. REST APIを提供しており、主要なシステムとの連携実績があります。個別のご相談も承ります。
```

**デザイン注意点**:
- Q&Aは2-3組が推奨
- 質問30文字、回答80文字以内
- 質問と回答を視覚的に区別する（質問は太字・アクセント色）

## 12. comparison_table - 比較表

**用途**: 複数項目を横並びで比較する表形式

**背景色**: 白 `#FFFFFF`

**使用可能な要素**: タイトル（##）、キーメッセージ（###）、テーブル

**記法例**:
```markdown
<!-- layout: comparison_table -->
## プラン比較
### 3つのプランから最適なものをお選びいただけます

| 項目 | ベーシック | スタンダード | プレミアム |
|------|-----------|-------------|-----------|
| 月額 | 1万円 | 3万円 | 10万円 |
| ユーザー数 | 5名 | 20名 | 無制限 |
| ストレージ | 10GB | 100GB | 1TB |
| サポート | メール | チャット | 専任担当 |
```

**デザイン注意点**:
- 3-5行 x 3-5列が推奨
- ヘッダ10文字、データ15文字以内
- ヘッダ行は背景色で区別する

## 13. image_with_text - 画像＋テキスト

**用途**: 画像を中心に据えて説明テキストを添える

**背景色**: 白 `#FFFFFF`

**使用可能な要素**: タイトル（##）、キーメッセージ（###）、画像パス（`![alt](path)`）、説明テキスト

**記法例**:
```markdown
<!-- layout: image_with_text -->
## システム構成図
### マイクロサービスアーキテクチャを採用しています

![システム構成図](images/architecture.png)

フロントエンドからAPIゲートウェイを経由して各マイクロサービスにアクセスする構成です。データベースはサービスごとに独立しています。
```

**デザイン注意点**:
- 画像がない場合は `assets/placeholder.png` が使用される
- 画像は左半分、テキストは右半分に配置
- 説明テキストは100文字以内

## 14. chart - グラフ

**用途**: 数値データをグラフで可視化する

**背景色**: 白 `#FFFFFF`

**使用可能な要素**: タイトル（##）、キーメッセージ（###）、テーブル（データ）、チャートタイプコメント

**チャートタイプ自動判定ルール**:

| 条件 | チャートタイプ |
|------|--------------|
| 値が%表記 or 合計が約100 | pie（100%積み上げ棒） |
| ラベルが時系列（年/月/Q1等） | bar（縦棒） |
| `<!-- chart_type: line -->` | line（折れ線） |
| それ以外 | horizontal_bar（横棒） |

**太字ラベルによる強調**: テーブルのラベルを `**太字**` にすると、その棒がアクセント色 `#3AA899` で表示される。

**記法例（横棒グラフ）**:
```markdown
<!-- layout: chart -->
## 顧客満足度調査
### 全カテゴリで高い評価を獲得しています

| カテゴリ | スコア |
|---------|-------|
| 使いやすさ | 4.5 |
| **サポート** | 4.8 |
| 機能性 | 4.2 |
| コスパ | 4.0 |
```

**記法例（縦棒グラフ - 時系列）**:
```markdown
<!-- layout: chart -->
## 売上推移
### 4四半期連続で成長を達成しています

| 四半期 | 売上(億円) |
|-------|-----------|
| Q1 | 2.5 |
| Q2 | 3.0 |
| Q3 | 3.8 |
| **Q4** | 4.5 |
```

**記法例（折れ線グラフ - 複数系列）**:
```markdown
<!-- layout: chart -->
<!-- chart_type: line -->
## ユーザー数推移
### アクティブユーザーが着実に増加しています

| 月 | 登録者 | アクティブ |
|----|-------|----------|
| 1月 | 1000 | 500 |
| 2月 | 1500 | 800 |
| 3月 | 2200 | 1200 |
| 4月 | 3000 | 1800 |
```

**記法例（100%積み上げ棒）**:
```markdown
<!-- layout: chart -->
## 売上構成比
### サービスBの比率が拡大しています

| カテゴリ | 割合 |
|---------|------|
| サービスA | 45% |
| **サービスB** | 35% |
| サービスC | 20% |
```

**デザイン注意点**:
- ラベルは10文字以内
- データ点は3-7個が推奨
- グラフ描画の詳細は [shape-helpers.md](shape-helpers.md) を参照

## 15. cta - 行動喚起

**用途**: プレゼンの最後に具体的な行動を促す

**背景色**: 薄グレー `#F5F5F5`

**使用可能な要素**: メッセージ（##）、説明（###）、ボタンテキスト（箇条書きの最初の項目）

**記法例**:
```markdown
<!-- layout: cta -->
## お問い合わせはこちら
### 導入に関するご質問やデモのご依頼を承っております

- 無料デモを申し込む
```

**デザイン注意点**:
- メッセージは20文字以内
- 説明は40文字以内
- ボタンテキストは15文字以内
- ボタンはアクセント色 `#3AA899` で中央配置
- 1プレゼンで末尾に1回のみ使用する
