# レイアウト選択ガイド

本ドキュメントはスライドの内容に応じて最適なレイアウトを選択するためのガイドである。
18種類のレイアウトの中から、コンテンツの種類に基づいて適切なものを選択する。

## 選択フローチャート

コンテンツの種類に応じて、以下のフローで判断する:

```
コンテンツの種類は?
│
├─ 表紙・導入           → title
├─ セクション区切り     → section
├─ 全体の流れを示す     → toc
├─ 数値・KPIを強調      → metrics
├─ 引用を紹介           → quote
├─ Q&A形式              → faq
├─ 行動を促す           → cta
├─ 画像が主役           → image_with_text
├─ データをグラフ化     → chart
├─ 比較表               → comparison_table
├─ 手順・ステップ       → numbered_list
├─ 2つの対比            → two_column
├─ 3つの並列            → three_column
├─ 4つの並列            → four_column
├─ ロードマップ・年表   → timeline
├─ 終了・お礼           → thank_you
├─ 2x2分析・マトリクス  → matrix
└─ 上記以外             → bullet_points（デフォルト）
```

## 各レイアウトの適用場面

### title
- **いつ使うか**: プレゼンテーションの表紙。タイトルとサブタイトルを表示する
- **使わない方がよい場面**: プレゼンの途中。表紙は冒頭1枚のみ

### section
- **いつ使うか**: 大きなトピックの区切り。セクション名を大きく表示する
- **使わない方がよい場面**: スライド枚数が少ない（5枚以下）プレゼンでは不要

### toc
- **いつ使うか**: プレゼン冒頭でアジェンダを示す。または中間サマリーとして使用する
- **使わない方がよい場面**: スライド枚数が少なく全体像の提示が不要な場合

### bullet_points
- **いつ使うか**: 汎用的な箇条書きコンテンツ。他のレイアウトに当てはまらない場合のデフォルト
- **使わない方がよい場面**: データや数値中心の内容（chart/metricsの方が適切）

### numbered_list
- **いつ使うか**: 手順、ステップ、優先順位のある項目を順序付きで示す
- **使わない方がよい場面**: 順序が重要でない並列情報（bullet_pointsの方が適切）

### two_column
- **いつ使うか**: 2つの要素の対比・比較。Before/After、現状/目標など
- **使わない方がよい場面**: 3つ以上の並列要素がある場合

### three_column
- **いつ使うか**: 3つの並列要素。特徴、メリット、カテゴリの並列表示
- **使わない方がよい場面**: 各項目の説明が長く60文字を超える場合

### four_column
- **いつ使うか**: 4つの並列要素。フェーズ、ステップ、カテゴリの概要
- **使わない方がよい場面**: 各項目の説明が長い場合（40文字制限あり）

### metrics
- **いつ使うか**: 2-4個の数値・KPIを大きく表示して強調する
- **使わない方がよい場面**: 数値が5個以上ある場合（comparison_tableの方が適切）

### quote
- **いつ使うか**: 顧客の声、著名人の言葉、調査結果の引用
- **使わない方がよい場面**: 短いフレーズや数値データ

### faq
- **いつ使うか**: 想定質問とその回答。Q&A形式で情報を整理する
- **使わない方がよい場面**: 質問が4つ以上ある場合（複数スライドに分割する）

### comparison_table
- **いつ使うか**: 複数項目を横並びで比較する表形式。製品比較、プラン比較
- **使わない方がよい場面**: 行数・列数が多すぎる場合（5行x5列が上限目安）

### image_with_text
- **いつ使うか**: 画像を中心に据えて説明テキストを添える。スクリーンショット、図解
- **使わない方がよい場面**: テキストだけで十分に説明できる場合

### chart
- **いつ使うか**: 数値データをグラフで可視化する。棒グラフ、折れ線、円グラフ
- **使わない方がよい場面**: データ点が2個以下（metricsの方がインパクトがある）

### cta
- **いつ使うか**: プレゼンの最後に具体的な行動を促す。ネクストステップ、連絡先
- **使わない方がよい場面**: プレゼンの途中。CTAは末尾1枚のみ

### timeline
- **いつ使うか**: プロジェクトのロードマップ、マイルストーン、年表、時系列のイベント
- **使わない方がよい場面**: 時系列でない並列情報（three_column / four_column の方が適切）

### thank_you
- **いつ使うか**: プレゼンの最後の締めくくり。感謝メッセージと連絡先
- **使わない方がよい場面**: プレゼンの途中。末尾1枚のみ。行動喚起が必要ならctaを使う

### matrix
- **いつ使うか**: SWOT分析、ポジショニングマップ、2軸での分類・比較
- **使わない方がよい場面**: 2項目の比較（two_column）や表形式の比較（comparison_table）の方が適切な場合

## ベストプラクティス

- **同じレイアウトの連続は2回まで**: 視覚的な単調さを避ける。3回以上連続する場合はレイアウトを見直す
- **title / section / cta / thank_you は各1回が目安**: これらは構造的な役割を持つため、多用すると冗長になる
- **全体のリズムを意識する**: テキスト系（bullet_points等）とビジュアル系（chart, metrics等）を交互に配置すると飽きにくい
- **迷ったら bullet_points**: 最も汎用的なレイアウト。まず bullet_points で作成し、後からより適切なレイアウトに変更する
- **情報量とレイアウトを合わせる**: 情報が多いスライドには bullet_points や comparison_table、少ないスライドには metrics や quote を選ぶ
