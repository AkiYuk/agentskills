# ワークフロー詳細

本ドキュメントはslide-generatorスキルの6ステップワークフローの詳細手順を定義する。
各ステップのインプット・アウトプット・作業内容を記載する。

## 全体フロー

```
input/元資料 → [1.目的確認] → [2.構成設計] → [3.レイアウト選択] → [4.テキスト調整] → [5.slides.md出力] → [6.PowerPoint生成] → output/*.pptx
```

各ステップは順序依存であり、前ステップのアウトプットが次ステップのインプットとなる。

---

## ステップ1: 目的確認

### インプット
- `input/` 配下の全ファイル（テキスト、PDF、画像等）

### 作業内容
1. `input/` 配下の全ファイルを読み込む
2. 以下の3要素を抽出する:
   - **ターゲット**: 誰に向けたプレゼンか（例: 経営層、開発チーム、顧客）
   - **ゴール**: プレゼンのゴール（例: 予算承認を得る、技術選定を決定する）
   - **期待アクション**: 聞いた人に何をしてほしいか（例: 承認する、導入を検討する）
3. 不明な場合はユーザーに質問して確認する

### アウトプット
- ターゲット・ゴール・期待アクションの定義

---

## ステップ2: 構成設計

### インプット
- ステップ1のターゲット・ゴール・期待アクション
- `input/` の元資料

### 作業内容
1. **キーメッセージの抽出**: 元資料から伝えるべき核心的メッセージを特定する
2. **情報のグルーピング**: 関連する情報をテーマごとにまとめる
3. **論理構造の選択**: プレゼン全体の論理構成を以下から選択する
   - **PREP**: 結論→理由→具体例→結論（汎用的）
   - **問題解決**: 課題提示→原因分析→解決策→効果
   - **比較提案**: 現状→選択肢比較→推奨案→期待効果
   - **時系列**: 過去→現在→未来（変遷・ロードマップ向け）
4. **各スライドの役割決定**: スライドごとに「何を伝えるか」を1文で定義する

### アウトプット
- スライド構成案（各スライドの役割リスト）
- 選択した論理構造

---

## ステップ3: レイアウト選択

### インプット
- ステップ2のスライド構成案

### 作業内容
1. 各スライドの内容に基づき、15パターンから最適なレイアウトを割り当てる
2. [layout-selection-guide.md](layout-selection-guide.md) のフローチャートに従って選択する
3. 以下のベストプラクティスを遵守する:
   - 同じレイアウトの連続は2回まで
   - title / section / cta は1プレゼンで各1回が目安
   - 全体のリズムを意識してレイアウトを変化させる

### アウトプット
- 各スライドへのレイアウト割り当て

---

## ステップ4: テキスト調整

### インプット
- ステップ2の構成案
- ステップ3のレイアウト割り当て

### 作業内容
1. [character-limits.md](character-limits.md) に基づき、各要素の文字数制限を確認する
2. テキストを制限に合わせて調整する
3. 超過時の対処:
   - **要約**: 文言を簡潔にまとめる
   - **分割**: 1スライドの情報量が多い場合は複数スライドに分割する
4. キーメッセージのルールを確認する:
   - 体言止め禁止
   - 20-40文字目安
   - 具体的な数値・固有名詞を含める

### アウトプット
- 文字数制限に適合したテキスト

---

## ステップ5: slides.md出力

### インプット
- ステップ4の調整済みテキスト
- ステップ3のレイアウト割り当て

### 作業内容
1. [layout-rules.md](layout-rules.md) の記法に従い、Markdown形式でスライドを記述する
2. `output/slides.md` に出力する
3. 各スライドは `---` で区切る
4. レイアウト指定は `<!-- layout: xxx -->` コメントで行う

### アウトプット
- `output/slides.md` ファイル

---

## ステップ6: PowerPoint生成

### インプット
- `output/slides.md`
- `config.json`
- テンプレートPPTX（オプション）

### 作業内容
1. 以下のCLIコマンドでPPTXを生成する:
   ```
   python scripts/slide_generator_pptx.py --markdown-file output/slides.md --config config.json
   ```
2. テンプレートを指定する場合:
   ```
   python scripts/slide_generator_pptx.py --markdown-file output/slides.md --config config.json --template assets/template.pptx
   ```
3. 出力ディレクトリを変更する場合:
   ```
   python scripts/slide_generator_pptx.py --markdown-file output/slides.md --config config.json --output-dir my_output
   ```

### アウトプット
- `output/<タイトル>.pptx` ファイル
